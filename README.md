# Xpounder Pages compatibility

Compatibility redirects for the moved RadioDesk and paper websites, with eleven
unchanged paper assets to preserve direct download links. The original asset
hashes and source revision are recorded in `compatibility-manifest.json`.

The site publishes `site/` using GitHub Pages. It has no custom domain and does
not change DNS. Hormuz keeps its own existing repository and Pages site; no
Hormuz route is included here. Do not recreate either moved repository slug,
because that would replace GitHub repository redirects.
