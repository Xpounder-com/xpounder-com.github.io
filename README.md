# Xpounder Pages compatibility

Compatibility pages for the moved RadioDesk and paper websites, with unchanged
paper assets to preserve direct download links. Source hashes and revision are
recorded in `compatibility-manifest.json`.

The site publishes `site/` using GitHub Pages. It has no custom domain.

The former product website, redirects, demos, branding and downloads have been
removed. Its old subtree is excluded from publication.

Keep the existing RadioDesk and paper destinations and assets. Repository slugs
for the transferred projects remain reserved so GitHub redirects keep working.
